# Maintainer records

These records support release preparation; they are not needed to use or build
Ritual Codec. Start with [release validation](../RELEASE_VALIDATION.md) for current
platform evidence and [the public release checklist](PUBLIC_RELEASE_CHECKLIST.md)
for remaining work.

| Record | Scope |
| --- | --- |
| [License and asset audit](LICENSE_ASSET_AUDIT.md) | Source, fonts, audio and packaged dependency notices |
| [History audit](history-audit.json) | Scoped Git-history screening and historical image review |
| [Baseline](BASELINE.md) | Reproducible pre-bitstream Linux engine measurements |
| [Release hardening](release-hardening.json) | Earlier Linux decoder and packaging checks |

Historical records describe their dated snapshots. They do not establish current
cross-platform compatibility or final listening approval.
