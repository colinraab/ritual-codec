# Ritual Codec 0.2.0

First experimental release: a spectral degradation effect with Classic and RIT
modes, available as a standalone audio file player/WAV exporter and AU/VST3
plug-ins. Includes two command-line tools for offline processing and `.rit` files.

## Downloads

**Apple Silicon (arm64), macOS 26.6 or later only.** Choose the ZIP you need:

| File | Contents |
| --- | --- |
| `ritual-codec-0.2.0-macos-arm64-standalone.zip` | Standalone app: playback, seeking, output selection and float WAV export |
| `ritual-codec-0.2.0-macos-arm64-au.zip` | Audio Unit for compatible Mac DAWs |
| `ritual-codec-0.2.0-macos-arm64-vst3.zip` | VST3 for compatible Mac DAWs |
| `ritual-codec-0.2.0-macos-arm64-cli.zip` | `ritual-codec` and `ritual-stream`, with WAV input |

Every ZIP includes the matching source, licenses, third-party notices, build
provenance and internal file checksums. App and plug-in source archives include
the configured JUCE source. `SHA256SUMS.txt` alongside the downloads checks the
four outer ZIP files. Windows, Linux and Intel/universal Mac binaries are not
included in this release.

## Mac security notice

**No Apple Developer ID signing or notarization.** The app and plug-ins use
ad-hoc signatures, which do not identify an Apple-verified publisher. macOS may
block them or show an unidentified-developer warning.

Extract the standalone ZIP and copy `STANDALONE/Ritual Codec.app` to Applications.
If opening is blocked and you trust the download, use **System Settings → Privacy
& Security → Open Anyway** when offered. For plug-in installation paths and
bundle-specific troubleshooting, read the
[install guide](https://github.com/colinraab/ritual-codec/blob/v0.2.0/docs/INSTALLING.md).
Do not disable Gatekeeper system-wide. Downloaded installation on a second Mac
has not been verified.

## What is included

- Classic spectral degradation with Budget, Competition, Memory, Punch, Crunch,
  Clock, Downsample, Mix and Output controls; four starting presets.
- RIT mode with a real encoded packet budget and displayed bitrate.
- Standalone playback, pause, stop, seeking, output-device selection, restored
  settings and background 32-bit float WAV export with the processing delay removed.
- Matching textured interface, embedded fonts, spectrum display and noisy app icon.
- Fixed 256-sample plug-in latency, latency-aligned mix and bypass.

## Validation and known limits

Nine automated Release suites pass. Existing local tests cover full-track
standalone playback/export, AU validation, REAPER AU/VST3 automation and session
restore, and a narrower Ableton VST3 playback/save/reopen check. See the
[validation record](https://github.com/colinraab/ritual-codec/blob/v0.2.0/docs/RELEASE_VALIDATION.md)
for exact fixtures, versions and scope.

This is experimental software: sound, presets and `.rit` format may change.
There is no output limiter or normalization; extreme settings may exceed full
scale. Start at moderate monitoring levels. The standalone exports WAV; `.rit`
files use `ritual-stream`. Optional MP3/FLAC CLI support is not in these portable
WAV-only CLI binaries.

Second-machine installation, physical audio-device disconnect, Intel Macs,
older macOS versions and broader DAW compatibility remain unqualified. Automated
checks do not replace final listening approval.
